# RentDays

Supervisor проектов на Windows VPS: запуск CMD-процессов, стоп/рестарт и контроль аренды по Google Таблице. Без Docker и контейнеров.

## Что умеет

- Запуск, остановка и перезапуск проектов (одна или несколько CMD-команд)
- Папки **Аренда** / **Без аренды**, компактный список
- Автостоп при истечении даты, автозапуск при продлении
- Автозапуск панели с Windows, восстановление прошлой сессии

## Установка

```bash
pip install -r requirements.txt
python main.py
```

## EXE

```bash
build.bat
```

Результат: `dist/RentDays.exe`

## Google Таблица

| A — Проект | B — Дата (ДД.ММ) | C — Юзернейм |
|------------|------------------|--------------|

Название в панели = название в колонке A. Таблица: **Поделиться → Все по ссылке → Читатель**.

### Куда вставить ссылку на таблицу

**В панели:** ⚙ **Настройки** → поле **ID таблицы**  
(из ссылки `docs.google.com/spreadsheets/d/ВОТ_ЭТОТ_ID/edit`)

**Вручную:** `data/settings.json` → `spreadsheet_id`
